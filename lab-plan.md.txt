# AWS IAM Home Lab – Progress Tracker

This file documents each phase of the AWS IAM home lab.

## Phase 1 – Environment Setup
- Created AWS Free Tier account
- Secured root account with MFA
- Configured password policy

## Phase 2 – IAM Fundamentals
- Created AdminUser, DevUser, and AuditUser
- Created groups (Developers, Auditors)
- Attached permissions using AWS managed policies
- Created a custom S3 List-Only policy
- Tested least privilege with S3 access
- Confirmed AdminUser has full access

## Phase 3 – Roles, Policies & Access Control Testing
**Objective:** Learn how IAM roles enable secure service-to-service access between EC2 and S3 while applying the principle of least privilege.

### What Was Done
- Created IAM role `EC2S3ReadOnlyRole` for EC2 → S3 access
- Attached AWS-managed policy `AmazonS3ReadOnlyAccess`
- Launched EC2 instance with role attached
- Tested read-only access (received AccessDenied on upload)
- Created custom policy `S3ReadWriteSpecificBucket` for targeted bucket access
- Attached custom policy to the role and retested (upload succeeded)

### Why It Matters
- Demonstrates how AWS Roles provide temporary, secure credentials
- Reinforces least privilege access control
- Shows how to validate and troubleshoot permissions using AWS CLI
- Replicates real-world cloud security workflow
